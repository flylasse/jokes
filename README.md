# Jokes

A curated personal joke collection. The list spans multiple humor styles — dark one-liners, adult, dad jokes, no-arms-no-legs name jokes, doctor-doctor, caveman, walks-into-a-bar, and kid-friendly tiers — with Lars as sole curator.

## Entry points

- **`THE_LIST.md`** — the master joke list. The project's deliverable and state file. Start here.
- **`AGENTS.md`** — how to work in this repo (instructions for any agent or contributor).

## How this project works

Candidate-approval workflow: jokes are proposed as labeled batches, Lars selects by letter, approved jokes are appended to THE_LIST with the running count updated. Nothing enters or leaves the list without explicit approval.
